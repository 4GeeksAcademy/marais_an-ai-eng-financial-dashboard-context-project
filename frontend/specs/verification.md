Se inspeccionaron `paths`, queries, respuestas 200 y los cinco esquemas de la tabla; no se afirma haber ejecutado todos los endpoints de datos en esa comprobacion. Al terminar se detuvo el backend para restaurar su estado inicial; no se arranco el servidor frontend.
| Ruta GET contrastada con OpenAPI | Parametros relevantes y esquema de respuesta 200 |

| `/api/metrics` | start_date/end_date y category/operation_type opcionales; sin business_type. Array de FinancialMovement. |
| `/api/metrics/facets` | Sin queries. MetricsFacets: operation_types, business_types, categories, min_date, max_date globales. |
| `/api/metrics/alerts` | threshold >= 0, default 0.3, sin maximo; group_by day/week/month, default month; fechas y business_type opcionales. Array de MetricsAlert. |
| `/api/metrics/categories/top` | operation_type income/outcome, default outcome; limit entero 1-20, default 5; fechas y business_type opcionales. Array de TopCategoryItem. |
| `/api/metrics/summary` | group_by day/week/month, default month; fechas, category, operation_type y business_type opcionales. Array de MetricsSummaryItem. |
