# Memoria del proyecto

Este directorio conserva contexto breve respaldado por archivos y verificaciones del repositorio. No sustituye el código, las pruebas ni las reglas para agentes.

- [producto.md](producto.md): qué muestra hoy el dashboard y qué datos consume. Actualizar cuando cambien las pantallas o el alcance observable del producto.
- [arquitectura.md](arquitectura.md): responsabilidades de frontend y backend y recorrido de las peticiones. Actualizar al cambiar rutas, proxy, contratos o composición de servicios.
- [stack-tecnologico.md](stack-tecnologico.md): tecnologías y versiones declaradas por el proyecto. Actualizar junto con manifiestos, Dockerfiles o herramientas.
- [estado-actual.md](estado-actual.md): resultados comprobados y asuntos pendientes. Actualizar después de nuevas verificaciones; distinguir siempre una prueba local de una integración de extremo a extremo.

Las instrucciones para agentes están en [`../.agents/rules/`](../.agents/rules/). Consultarlas al trabajar; no duplicarlas aquí.
